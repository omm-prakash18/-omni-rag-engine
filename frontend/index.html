Design Philosophy: Phase Before You Scale

The original concept jumps straight to Kafka + dual-DB + multi-agent CRAG + live WebSockets. That's a production architecture for a problem — contradiction detection quality — that hasn't been validated yet. Do not let an agent skip straight to Phase 2's infra. The infra is the easy part.

Roadmap

Two-Phase Delivery

Phase 1 — Active ~2–3 Weeks

MVP — Validate the Hard Problem

Batch ingestion, single synthesis pass, static graph render. Prove the LLM can reliably distinguish real contradictions from scope/methodology mismatches.

  • ✓ Polling-based ingestion (APScheduler)
  • ✓ Semantic chunking + metadata extraction
  • ✓ LangGraph 4-node pipeline
  • ✓ FastAPI REST + WebSocket endpoint
  • ✓ Confidence indicator per contradiction
  • ✓ Source-tracing split view panel
  • ✓ Temporal slider (client-side)
Gate to Phase 2: >85% classifier precision on eval set
Phase 2 — Locked After Gate

Production — Scale the Infra

Add streaming ingestion and live UI only once Phase 1 precision is measured and acceptable. The infra is the easy part — don't skip the hard part.

  • → Kafka producers per source category
  • → WebSocket live streaming gateway
  • → Live agent reasoning panel
  • → Saved queries / watchlist alerts
  • → Export/share analysis (PDF / link)
  • → Multi-language source support
Unlocked by: Phase 1 eval harness passing

Contradiction Taxonomy (4-Way)

direct_contradiction

Same entity · same metric · same scope · different value. The real deal. Highest severity.

stale

One claim's published_at is much older — likely superseded, not actually conflicting.

scope_mismatch

Different date range, geography, or population. Not a real conflict — different questions entirely.

methodology_mismatch

Explicitly different calculation method (CPI vs PCE, core vs headline). Disagrees on method, not facts.

Know Before You Build

Open Risks to Track

HIGH

Classifier Precision/Recall

Needs a real eval harness — not just vibes. Build a 50-100 example hand-labeled set before trusting the classifier in the UI. False positives kill credibility fast.

HIGH

Source Content Licensing

No raw redistribution of full articles. Pull licensed summaries/APIs only. Full article text requires redistribution rights.

MED

Graph Readability at Scale

Clustering strategy must be decided before launch, not bolted on. ~30 visible nodes threshold, expand-on-click groups.

MED

LLM Cost Model

Query-time: 4 LLM calls per query. Ingestion-time: 1 call per chunk. Keep these separate in cost monitoring — streaming volume can silently blow up spend.
